How it works

A clean workflow for building topic-aware study plans and improving them with feedback.

1

Login

Students or admins enter the platform through a secure role-aware flow.

2

Build Profile

Add subjects, scores, weak point, learning style, focus topics, and daily study time.

3

Generate Roadmap

Select plan length and mode, then create subject-wise daily tasks with model-backed strategy guidance.

4

Track & Improve

Complete tasks, review dashboard progress, and submit feedback that rewards the adaptive policy.
